# lijst met alle routes

- GET       /api/gebruikers          retourneerd alle gerbuikers, gaat waarschijnlijk gebruikt worden in dashbord voor admin
- POST      /api/gebruikers          maak nieuwe gebruiker aan
- GET       /api/gebruikers/:id      1 gebruiker retourneren
- PUT       /api/gebruikers/:id      gebruiker updaten
- DELETE    /api/gebruikers/:id      gebruiker verwijderen
